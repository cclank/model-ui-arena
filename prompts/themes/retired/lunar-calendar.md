[主题] 农历日历
目标：构建一个“公历 + 农历”双历月视图与日期查询器，考察历法算法正确性、信息层级与键盘可达性的综合能力。所有农历、节气数据必须由页面内代码计算得出，禁止请求接口或引用外部数据文件。
视觉要求：尽量做成精美无比的卡片，充分发挥模型的想象力和审美。配色、字体、节气与节日的视觉表达、动效细节均可自由发挥，在保证信息层级清晰、农历数据正确的前提下追求最高的审美完成度。

必做功能：
1. 月视图网格（周日或周一起始均可）：每格显示公历日 + 农历日（初一处显示农历月名，如“八月”，闰月须标“闰”），当天高亮，可前后翻月、切换年份、回到今天
2. 农历算法正确：1900-01-31 至 2100-12-31 范围内正确处理大小月与闰月（如 2025 闰六月、2033 闰十一月），春节日期必须准确
3. 显示 24 节气与至少 6 个传统节日（春节、元宵、端午、七夕、中秋、重阳、除夕、腊八任选）
4. 日期查询（自动校验入口）：页面必须包含 id 为 `q-date` 的 `<input type="date">` 与 id 为 `q-result` 的结果区域；输入变更后结果文本须包含以下片段（顺序不限）：
   `农历：<干支>年 <闰?><月名>月 <日名>`、`生肖：<字>`、`节气：<名称或无>`、`节日：<名称或无>`
   月名使用 正/二/三/四/五/六/七/八/九/十/冬/腊，日名使用 初一…初十 / 十一…十九 / 二十 / 廿一…廿九 / 三十
   示例：`农历：乙巳年 闰六月 初一 · 生肖：蛇 · 节气：无 · 节日：无`
5. 选中日期详情面板：公历、星期、农历、干支年、生肖，以及当天节气或节日
6. 键盘可达：方向键移动选中日期（跨月自动翻页）、PageUp / PageDown 翻月、可聚焦元素有可见焦点样式
7. 390px 宽度下网格完整可见、无横向溢出

加分项：
- 节气用太阳视黄经天文公式计算，而非查表或硬编码
- 日干支、距春节倒计时、本年第几天 / 第几周
- 法定假日或调休标记、宜忌趣味文案
- 浅色 / 深色主题自动跟随系统

反作弊：校验脚本（`node scripts/verify-lunar.mjs <model>`）会用真值锚点与 1900–2100 之间的随机日期驱动 `#q-date` 比对结果；只硬编码当前月份、或结果格式不可解析，均记为功能不合格。

[主题] 日出日落与月相
目标：构建一个"给定地点与日期，展示当天日出、日落与月相"的天文卡片，考察天文算法正确性、信息层级与视觉表现力的综合能力。所有数值必须由页面内代码计算得出，禁止请求接口、禁止引用外部数据文件、禁止用查表或硬编码代替计算。
视觉要求：这是"计算 + 审美"系列里画面最直观的一道题。至少要有一条天穹弧线（地平线、太阳轨迹、日出与日落位置）与一枚月相盘（亮面形状与朝向随相位变化），背景色调随昼夜与时刻变化。配色、字体、动效可自由发挥，但信息层级要清晰，数值必须算对。

必做功能：
1. 输入区（自动校验入口）：页面必须包含以下 id 的输入元素：`q-lat`（纬度，number，-90 ~ 90）、`q-lon`（经度，number，-180 ~ 180）、`q-date`（`<input type="date">`）、`q-tz`（时区偏移小时数，number，可为小数如 5.5、-3.5）；以及 id 为 `q-result` 的结果区域。任一输入变更后，结果文本须包含以下片段（顺序不限）：
   `日出：HH:MM`、`日落：HH:MM`、`月相：<名称>`、`照亮：NN%`
   时间为所给时区的 24 小时制、两位补零；极昼时写 `日出：极昼 · 日落：极昼`，极夜时写 `日出：极夜 · 日落：极夜`
   示例：`日出：05:49 · 日落：18:34 · 月相：残月 · 照亮：5%`
2. 日出日落算法：按标准定义（太阳中心高度 -0.833°，含大气折射与视半径），推荐 NOAA 算法或同等精度方案（须含时差 Equation of Time 与太阳赤纬），误差在 ±2 分钟内；正确处理南半球、跨日期变更线、极昼与极夜
3. 月相：按该日期在所给时区 12:00 时刻计算。输出照亮比例（0–100 的整数百分比）与月相名称。名称按相位比例 p 判定，p = 月亮相对太阳的地心黄经差 / 360°（新月 0、上弦 0.25、满月 0.5、下弦 0.75）：|p − 0| ≤ 0.03 新月，|p − 0.25| ≤ 0.03 上弦月，|p − 0.5| ≤ 0.03 满月，|p − 0.75| ≤ 0.03 下弦月；其余区间依次为 蛾眉月（0.03 ~ 0.22）、盈凸月（0.28 ~ 0.47）、亏凸月（0.53 ~ 0.72）、残月（0.78 ~ 0.97）
4. 天穹图：地平线 + 当天太阳轨迹弧线，标出日出、正午、日落位置；按当前时刻（或页面上的时间滑杆）显示太阳位置；夜晚时段显示月亮
5. 月相盘：用代码绘制（SVG 或 canvas），亮面形状与朝向随 p 连续变化，按北半球视角即可
6. 预设地点：至少 6 个城市快捷按钮（须含一个南半球城市与一个北纬 60° 以上城市），点击后填充经纬度与时区；默认展示北京与今天
7. 390px 宽度下完整可见、无横向溢出；可聚焦元素有可见焦点样式

加分项：
- 时间滑杆拖动一天内时刻，天空色与太阳位置联动
- 昼长、与前一日昼长之差、正午太阳高度角、蓝调时刻或黄金时刻
- 月出月落时间
- 浅色 / 深色主题自动跟随系统

反作弊：校验脚本（`node scripts/verify-sun-moon.mjs <model>`）会用真值锚点与随机地点、随机日期驱动 `#q-lat` / `#q-lon` / `#q-date` / `#q-tz` 比对结果；只硬编码预设城市、只算当前日期、或结果格式不可解析，均记为功能不合格。

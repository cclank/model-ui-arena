[主题] 鹈鹕骑自行车（2D SVG 动态版）
目标：只画一个主体——一只鹈鹕骑着自行车，做成会动的 2D SVG 插画。这是经典的模型 SVG 基准题，本题在此基础上加入动态要求，测试模型对鸟类解剖与机械结构的还原，以及用 SVG 原生动画组织连贯循环动效的能力。

必做功能：
1. 鹈鹕特征：长喙 + 可辨识的喉囊、弯曲的粗颈、流线型身体、分层翅膀与黑色飞羽、尾羽、蹼足；侧视，自然地坐在坐垫上
2. 自行车结构：前后轮（轮胎、轮圈、辐条）、三角车架（上管 / 下管 / 座管 / 后叉）、前叉与车把、坐垫、曲柄与脚踏、链轮与链条，比例合理；鹈鹕的蹼足踩在脚踏上、翅膀搭在车把上
3. 动态（核心）：
   - 车轮转动，辐条旋转可见
   - 蹬踏：曲柄旋转，双腿随脚踏做周期屈伸，脚始终踩在脚踏上（不能悬空、不能穿模）
   - 身体随蹬踏节奏轻微起伏，头颈 / 喉囊 / 尾羽至少一处有跟随的次级动效
   - 场景循环滚动形成前进感（路面标线、护栏 / 树木 / 云层等），至少两层不同速度
   - 所有动画无缝循环，页面打开即自动播放；静态首帧本身也是一张完整画面
4. 技术要求：动画必须用 SVG SMIL（animate / animateTransform / animateMotion）或 CSS 实现；禁止 canvas、位图、外部库；JavaScript 仅允许少量用于增强（如切换速度），不得用 JS 逐帧重绘主体
5. 场景：有天空、地面 / 道路与远景（海边、乡村、城市任选），色彩与光线统一
6. 移动端 390px 宽度下鹈鹕与自行车仍清晰可辨

加分项：
- 三层以上视差滚动、路面颠簸反馈、影子随起伏变化
- 喉囊里有鱼、路过的海鸥 / 螃蟹等小配角
- 羽毛、辐条、链条等细节密度高，分层命名清晰
- 可点击切换速度或昼夜

反作弊：禁止 `<img>`、base64 / `data:` 图片、`<canvas>`、emoji 或现成 SVG 素材；所有图形必须手绘。
